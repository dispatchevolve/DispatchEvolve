# DispatchEvolve

**Autonomous Policy Evolution for Industrial Ride-Hailing Dispatch Engines with Multi-Objective Constraints**

DispatchEvolve is a framework for evolving mature industrial dispatch engines while respecting coupled, system-level constraints. It combines trace-grounded local policy evolution with Pareto-guided global engine integration.

## Project status

This repository is being prepared for the KDD 2027 ADS submission. The implementation and reproducibility artifacts will be released here.
